## Verifiers

| script | what it does |
|---|---|
| `verify_dd.py` | pure-stdlib reference: simplicity, degree, connectivity, BFS from **every** vertex. O(N·E), so it is used on the small graphs. |
| `verify_big.py` | the same exhaustive all-pairs check done bit-parallel (64 sources per pass, numpy) — every ordered pair, in seconds. |
| `verify_vt.py` | *proves* vertex-transitivity from the edge list — two suggested left-translation permutations are checked to be bijections that map every edge to an edge, and the group they generate is checked to be transitive — after which one BFS gives the diameter. A wrong suggestion fails the check rather than yielding a wrong answer. |
